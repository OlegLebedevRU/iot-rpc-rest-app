# Исследование: формула создания SN в флоу legacy-сертификата

## Результат

### Формула SN

**Файл:** `app-service/core/services/legacy.py:25-31`

```python
PLATFORM = "4"

def generate_device_sn(device_number: int) -> str:
    device_part = f"{device_number:07d}"
    rand_first = str(random.randint(1, 9))
    rand_rest = "".join([str(random.randint(0, 9)) for _ in range(4)])
    random_part = rand_first + rand_rest
    date_part = datetime.now().strftime("%d%m%y")
    return f"a{PLATFORM}b{device_part}c{random_part}d{date_part}"
```

**Формат:** `a4b{device_number_7digits}c{5_random_digits}d{DDMMYY}`

**Пример:** `a4b0012345c73291d200826`

| Часть | Значение | Формат |
|-------|----------|--------|
| `a` | префикс | литерал |
| `4` | PLATFORM | константа (строка 22) |
| `b` | разделитель | литерал |
| `0012345` | device_number | 7 цифр, zero-padded |
| `c` | разделитель | литерал |
| `73291` | случайное число | 5 цифр (первая 1-9, остальные 0-9) |
| `d` | разделитель | литерал |
| `200826` | текущая дата | ДДММГГ |

### API-эндпоинт

**Файл:** `app-service/api/api_v1/legacy.py:23`

- `GET /api/v1/devices/map_legacy_crt/`
- Сертификат передаётся в заголовке `X-SSL-Client-Cert`
- Скрыт из OpenAPI (`include_in_schema=False`)

### Полный флоу (`process_legacy_certificate`, legacy.py:190-261)

1. URL-decode заголовка `X-SSL-Client-Cert`
2. Парсинг сертификата → извлечение `OU` → `device_number` (только цифры)
3. Проверка существования устройства в БД (`DeviceRepo.get_device_sn`)
4. Если устройство есть → переиспользовать существующий SN
5. Если нет → `generate_device_sn(device_number)` + регистрация в БД (`org_id=0`)
6. Генерация RSA-ключа + CSR (CN=SN, OU=device_part)
7. Запрос подписанного сертификата у внешнего CA (`settings.leo4.cert_url`)
8. Создание PFX (пароль: `pfx-{device_number}-{random_4_digits}`)
9. Возврат: base64 PFX, пароль, даты, SN, device_id
