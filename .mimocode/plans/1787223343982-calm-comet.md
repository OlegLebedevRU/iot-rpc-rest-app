### Как конфигурация работает (поток данных)

```
tb_Variables (SQL) → sysMainFormId = "142"
        ↓
clsVariable.MainFormId → int 142
        ↓
clsModesManager.CurentAppMode → (AppMode)142 = AppMode.AKH
        ↓
clsNavigatePagesManager → SELECT * FROM tb_Forms WHERE Id = 142
        ↓
tb_Forms: ClassName='pgMainAKH', Description='Главная форма AKH'
        ↓
WPF page pgMainAKH.xaml.cs → UI
```

### Дополнительно: `tb_Forms` в БД

Таблица `tb_Forms` — это БД-сторона справочника. Колонки:
- `Id` (int, PK) — совпадает со значением `AppMode`
- `ClassName` (string) — имя WPF-страницы
- `InterfaceName` (string) — всегда "IPage" для главных форм
- `Description` (string) — описание на русском
- `FormTypeId` (int) — тип формы (`PageType` enum, 1 = Main)
