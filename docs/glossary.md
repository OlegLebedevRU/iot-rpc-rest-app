# 📖 Глоссарий LEO4

[← Документация](README.md)

| Термин | Значение |
| :--- | :--- |
| **SN / CN** | Серийный номер устройства; совпадает с Common Name клиентского сертификата и используется в MQTT-топиках |
| **mTLS / PKI** | Двусторонняя TLS-аутентификация и инфраструктура сертификатов устройств |
| **RPC** | Асинхронная команда: TSK → необязательный ACK → REQ → RSP → RES → CMT |
| **Trigger** | Сервер анонсирует задачу; устройство выбирает её адресным REQ |
| **Polling** | Устройство запрашивает следующую допустимую задачу с нулевым UUID |
| **Correlation Data** | UUID задачи в RPC или UUID публикации события; [форматы](correlation-data-guide.md) |
| **method_code** | Код команды в заголовке задачи и transport User Property; [реестр](method-codes-reference.md) |
| **TSK / RSP** | Анонс без параметров / полный конверт с параметрами `payload` |
| **RES / CMT** | Результат устройства / подтверждение сохранения результата сервером |
| **result_uid / result_id** | UUID логического результата на устройстве / ID записи результата в IoT |
| **ext_task_id / ext_id** | Внешняя строка задачи REST / числовой ID результата устройства |
| **EVT / EVA** | Событие устройства / подтверждение его обработки сервером |
| **event_type_code** | Код типа события из MQTT User Properties; [реестр](event-types-reference.md) |
| **Tag** | Числовое имя свойства JSON, например `304` — номер ячейки; [справочник](event-property-tags.md) |
| **Gauge** | Текущий снимок телеметрии вместо дискретной истории; по умолчанию код `44` |
| **DONE** | Сохранён RPC-результат; успех проверяется отдельно, физический эффект подтверждается событием |
| **TTL / deadline** | Минуты внешнего контракта / абсолютный срок задачи на сервере; [правила](TTL.md) |
| **Tenant / org_id** | Организация, в пределах которой проверяется доступ и фиксируется принадлежность события |
| **Webhook** | HTTP POST о новом событии или результате; [контракт](3-webhooks.md) |
| **Control plane** | Межсервисные интерфейсы и оперативное управление, включая `ctl` |
| **Unified lease** | Общая монопольная аренда удалённого сеанса; [Remote Input](remote-input-protocol.md) |
| **L4FM v2** | Файловый менеджер с RPC7021/7023 и `fmc/fmr`; [контракт](file-manager-v2.md) |
| **Channel Probe** | Отдельная маркированная проверка транспорта без хранимой задачи/события; [контракт](channel-probe.md) |
| **Integration Bus** | AMQP-интеграция доменных сервисов; статус и предложение описаны в [RFC](rfc-integration-bus.md) |

Сверено с `master` на 09.10.2026.
