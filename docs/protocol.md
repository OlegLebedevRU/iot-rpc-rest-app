## 📦 Базовая структура события

```json
{
  "101": 20338,
  "102": "2026-10-09T08:00:00Z",
  "200": 13,
  "300": [{"304": 5}]
}
```

`101` — ID события устройства, `102` — время, `200` — тип, `300` — массив объектов свойств. MQTT User Properties `event_type_code`, `dev_event_id`, `dev_timestamp` передаются отдельно: сервер не выводит их автоматически из JSON.
